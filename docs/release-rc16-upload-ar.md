# تسليم K-Waiter 3.0.0-rc.16

هذا الإصدار يكمل إدارة أكثر من طابعة شبكة محلية من التابلت نفسه.

## الجديد

- إضافة وتعديل وحذف واختبار عدد غير محدود عمليًا من طابعات TCP المحلية.
- تحديد طابعة الفاتورة الرئيسية بصورة مستقلة.
- توجيه KOT إلى طابعة المطبخ أو المشروبات أو الكاشير أو إلى تصنيفات محددة.
- تعيين طابعة بديلة، واستخدامها تلقائيًا عند فشل الطابعة الأساسية.
- إعداد صوت الطباعة ودرج النقدية لكل طابعة محلية.
- فحص كل الطابعات المحلية في شاشة صحة الجهاز.
- ترحيل إعداد IP القديم تلقائيًا إلى أول طابعة دون فقد الإعداد المحفوظ.
- دعم عربي وإنجليزي للواجهة الجديدة.

## ملاحظات النشر

- Android: `versionCode=300016` و`versionName=3.0.0-rc.16`.
- iOS: `MARKETING_VERSION=3.0.0` و`CURRENT_PROJECT_VERSION=300016`.
- لا يوجد SQL جديد لهذا الإصدار؛ قائمة الطابعات المحلية جزء من إعدادات الجهاز وتُحفظ داخل `settings_json` وعلى التابلت.
- يجب أن تكون كل طابعة TCP على نفس شبكة Wi-Fi الخاصة بالتابلت، وغالبًا تستخدم المنفذ `9100`.

## اختبار الفرع

1. أضف طابعة فاتورة واخترها كطابعة رئيسية.
2. أضف طابعة مطبخ وطابعة مشروبات، وحدد التصنيفات لكل واحدة.
3. نفّذ اختبارًا مستقلًا لكل طابعة.
4. افصل الإنترنت مع إبقاء Wi-Fi المحلي، ثم أنشئ طلبًا وأرسله للمطبخ.
5. جرّب فاتورة ودفعًا نقديًا وفتح الدرج.
6. أوقف الطابعة الأساسية واختبر التحويل إلى الطابعة البديلة.
